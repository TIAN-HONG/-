# 试试咨询主站与小程序/H5 原型

本目录已拆成两个独立包：

## `website/`

PC 主站原型，包含：

- `site.html`：主站首页
- `client.html`：客户入口
- `partner.html`：合伙人入口
- `candidate.html`：求职者入口
- `developer.html`：发展人工具台

## `miniapp-h5/`

微信 H5 / 小程序风格裂变工具原型，包含：

- `invite.html`：合伙人裂变入口

## 本地访问

如果本地静态服务跑在 `http://127.0.0.1:4173/`：

- 主站：`http://127.0.0.1:4173/website/site.html`
- H5：`http://127.0.0.1:4173/miniapp-h5/invite.html`

原始业务资料目录已通过 `.gitignore` 排除，不会提交到仓库。
