# 试试咨询 PC 主站原型

这是试试咨询 PC 主站原型，独立于 H5 裂变工具部署。

## 页面

- `index.html`：演示入口
- `site.html`：PC 主站首页
- `client.html`：客户入口
- `partner.html`：合伙人入口
- `candidate.html`：求职者入口
- `developer.html`：发展人工具台
- `../miniapp-h5/invite.html`：微信 H5 裂变工具入口

## 核心表达

- 试试咨询不是传统猎头公司，而是去中心化招聘交易平台。
- 主站负责建立品牌信任，说明客户服务、合伙人机制、求职者入口和系统能力。
- 合伙人入口会跳转到独立 H5 包，H5 负责发展人私域分享、候选合伙人了解平台、报名分享会、提交意向和前置状态推进。
- `with_hr` 继续承接正式入职、做单、协同、分佣和运营管理。

## 一期边界

- 本项目是静态原型，数据暂存在浏览器 `localStorage`。
- 收益、周期和岗位匹配测算只用于产品演示，不构成收入、交付周期或录用承诺。
- 腾讯签、背调工具、企业微信加入等外部工具一期以人工状态记录表示。
- 原始业务资料文件不提交到仓库。
